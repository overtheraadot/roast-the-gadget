# roast-the-gadget

One entry for make.fun's "One-Line Roast: The Gadget You Use Every Day"
bounty: a single original roast line about my phone — the gadget I use
every day.

> My phone's 128 GB is 127 GB of screenshots I swore I'd read later and 1 GB of food I already ate.

`main.py` writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`). Deterministic, stdlib only, no network, no model
calls.
